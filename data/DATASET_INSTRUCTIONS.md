# Dataset instructions

The project expects \`Battery_dataset.csv\` in this directory.

The dataset file supplied during development was described as NASA lithium-ion battery data, but the exact source and redistribution terms for the transformed CSV have not been independently confirmed. To avoid publishing data without permission:

1. Locate the original download/source URL and read its usage terms.
2. Confirm the CSV can legally be redistributed in a public repository.
3. If permitted, place the file here as \`Battery_dataset.csv\` and document its exact source and citation.
4. If redistribution is not permitted or unclear, keep the file local and follow the source's authorized access instructions.

Expected columns: \`battery_id\`, \`cycle\`, \`chI\`, \`chV\`, \`chT\`, \`disI\`, \`disV\`, \`disT\`, \`BCt\`, \`SOH\`, and \`RUL\`.
