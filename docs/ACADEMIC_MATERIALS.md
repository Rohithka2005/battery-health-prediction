# Academic materials: publication checklist

The original report and presentation are intentionally not included in this package yet. Their text includes student names and student IDs, and some claims need technical review.

Before adding redacted public versions:

- Remove student IDs and any personal contact details.
- Confirm all team members agree to public sharing of names and work.
- Confirm university/course/institution policies permit publication.
- Correct claims about model performance and feature importance using the reproduced evaluations.
- Add dataset provenance and citations.
- Export the reviewed, redacted versions to PDF and inspect every page/slide for identifiers, including image-based text and speaker notes.
